#  Platforme_Test_Api

Une plateforme complète de test et de supervision d'APIs permettant de configurer des cibles, définir des endpoints, 
créer des scénarios de test (fonctionnels, performance, sécurité, résilience) 
et exécuter des validations automatisées.

---

##  Tech Stack

* **Frontend :** Angular (Standalone Components, Signals, RxJS)
* **Backend :** Spring Boot (Java, REST API)
* **Tests & Benchmarks :** k6, JUnit / RestAssured
